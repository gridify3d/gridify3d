# Gridify3D

Turn STL models into artistic pattern, grid and lattice-based 3D structures.

## ✨ Vision
Gridify3D opens new creative possibilities for 3D printing by transforming solid models into expressive grid and frame designs.

## 🚀 Features
- Convert STL models into lattice / grid structures
- Create artistic frame-based designs
- Explore new visual styles
- Generate unique printable objects
